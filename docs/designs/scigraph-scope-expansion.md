## Vision

### 10x Check
Transform SciGraph from an in-memory Python library (`11aa6f8`, 30-paper benchmark `F1 = 1.0000`, `0` fabricated DOIs/p-values) into a complete CLI + Interactive HTML Claim-Graph & Contradiction Studio + Quantitative Regime Delta Solver + SARIF v2.1.0/JSON CI Audit Gate + Effect-Size Statistical Power Calculator for ~2x effort (~45 minutes in CC / ~3 days human team) with zero new third-party dependencies.

### Platonic Ideal
A biotech or materials R&D researcher runs `scigraph report --format html --output report.html` or `scigraph report --format sarif` from the terminal. In under 20 milliseconds, SciGraph orders multi-column PDF text blocks, verifies every DOI, quote span, p-value, and sample size `n` verbatim against source character offsets, flags any fabricated paper DOI or claim citation as a SARIF v2.1.0 error (`SCIGRAPH-VERIFY-001`), computes exact quantitative regime deltas (`28.0 C -> 37.0 C`, `65% RH vs 130 C`) across conflicting papers, sizes falsifiable replication experiments using parsed standardized effect sizes (`alpha = 0.01, power = 0.90`), and outputs a zero-dependency interactive HTML explorer for side-by-side evidence inspection.

## Accepted Scope (added to this plan)
- `EXP-1`: `src/scigraph/cli.py`, `render_markdown_report` in `src/scigraph/exporters.py`, and `[project.scripts] scigraph = "scigraph.cli:main"` in `pyproject.toml` supporting `benchmark`, `verify`, and `report --format {markdown,html,sarif,json} [--output <path>] [--fail-on-contradictions]` with exit codes `0`/`1`/`2`.
- `EXP-2`: `src/scigraph/explorer.py` (`render_claim_graph_html`) rendering an XSS-safe (`html.escape`), zero-CDN interactive HTML explorer with dedicated `ContradictionKind` and `EdgeRelation` filter bars, verbatim character-offset quote cards, and experiment protocols.
- `EXP-3`: `src/solver/regime.py` (`RegimeParameter` with dimensions `temperature`, `humidity`, `current_density`, `molarity`, `mass_concentration`, `frequency`, `c_rate`; `extract_regime_parameters`; `compute_regime_delta`) wired into `detect_contradictions` in `src/solver/symbolic.py`.
- `EXP-4`: `src/scigraph/exporters.py` (`export_json_bundle`, `export_sarif_v210`) emitting deterministic JSON bundles and OASIS SARIF v2.1.0 reports (covering both `report.doi_verified == False` and failed `ClaimVerificationResult` entries under `SCIGRAPH-VERIFY-001`) with `artifactLocation.uri = f"papers/{paper_id}"`.
- `EXP-5`: `parse_standardized_effect_size` and `compute_powered_sample_size` wired into `propose_falsifiable_experiments` in `src/solver/symbolic.py`, scaling `FalsifiableExperiment.recommended_sample_size` at `alpha = 0.01, power = 0.90` via `max(base_n, total_powered_n)` where `total_powered_n = min(2000, n_per_arm * 2)`, with fallback to `base_n = max(40, 2 * max(n_a, n_b))` when both claims lack effect-size strings.
- `SEC-1`: Boundary hardening (`MAX_PDF_BYTES = 25 MiB`, `%PDF-` header check, `latin-1` stream decode, explicit `/FlateDecode` `ValueError`, and same-directory `NamedTemporaryFile` + `os.replace` atomic `--output` writes).
